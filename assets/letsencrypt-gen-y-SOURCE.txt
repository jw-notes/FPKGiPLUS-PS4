Why: GitHub's release download host (release-assets.githubusercontent.com)
serves a leaf issued by YR1, whose chain is YR1 -> Root YR (cross-signed by
ISRG Root X1) -> ISRG Root X1. Root YR is not yet in Mozilla's bundle, and the
PS4 firmware's TLS library does not complete that cross-signed path, so every
homebrew update check failed with 0x8095f00c (verify flags 0x20).

Every certificate here verifies against ISRG Root X1 already in cacert.pem
(intermediates through the publisher's root-yr-by-x1 / root-x2-by-x1 /
root-ye-by-x2 cross-certificates), and each self-signed root has the same key
as its X1/X2 cross-signed form. Trusting these directly skips ancestor checks
above them; it is not limited to one hostname. Leaf signature, hostname and
date checks remain enabled. No peer-delivered certificate is added to trust
at runtime.
